# CineRef project website — GitHub draft

This branch contains a **static GitHub Pages scaffold** under `cineref/`. It has not been merged into the default branch or deployed.

## Complete project
The complete offline project (paper-grounded introduction, five generated MP4 demos, ten character reference images, extracted Figure 2, benchmark results, and local PDF) has been prepared as a downloadable ZIP in the chat conversation. It is **not committed to this public GitHub repository**.

## Double-blind review
The submitted manuscript, **CineRef: Cinematic Reference-Guided Audio-Video Generation**, is marked **under review at ICLR 2027** and lists anonymous authors. Posting a full paper site on an identifiable personal GitHub account can reveal authorship. Confirm with coauthors and relevant venue policies before publicly deploying the full site, PDF, or demo media.

## Usage
The existing `cineref/index.html` is a no-build responsive scaffold with five media placeholders. Once publication is authorized, copy the contents of the complete downloadable local project to the `cineref/` folder and review all distribution permissions and URLs.

**No manuscript PDF, training code, model weights, or video assets have been pushed to this public branch.** The manuscript states code will become available upon acceptance.
